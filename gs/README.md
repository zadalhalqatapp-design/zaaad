# زاد الحلقات — دليل الإعداد والنشر

## المتطلبات
- حساب Google
- Google Sheets
- Google Apps Script
- Vercel أو Netlify (للنشر)

---

## الخطوة 1: إعداد Google Sheets

1. أنشئ ملف Google Sheets جديد وسمّه **قاعدة بيانات زاد الحلقات**
2. ضع هذا الملف داخل مجلد Google Drive الرئيسي **زاد الحلقات**
   - أنشئ المجلدات الفرعية: الكتب PDF، الصوتيات، الشهادات، صور الطلاب، الشعارات والهوية، النسخ الاحتياطية، المستندات

---

## الخطوة 2: إعداد Google Apps Script

1. من ملف Google Sheets: **Extensions → Apps Script**
2. احذف الكود الافتراضي
3. أنشئ ملفًا لكل ملف من مجلد `gs/` في هذا المشروع:
   - `Code.gs` (نقطة الدخول)
   - `Config.gs` (تعريف الأوراق)
   - `Utils.gs` (أدوات مساعدة)
   - `Setup.gs` (التهيئة)
   - `Auth.gs` (المصادقة)
   - `Students.gs` (إدارة الطلاب)
   - `Staff.gs` (إدارة المشرفين والمديرين)
   - `Hadiths.gs` (الأحاديث والإنجاز)
   - `Cycles.gs` (الدورات والشهادات)
   - `Communication.gs` (الرسائل والإشعارات)
   - `Management.gs` (الإعدادات والسجل والنسخ)
   - `Books.gs` (الكتب المتعددة وتعيينها للطلاب)
4. انسخ محتوى كل ملف `.gs` إلى الملف المقابل في Apps Script

---

## الخطوة 3: تهيئة قاعدة البيانات

1. في Apps Script، اختر الدالة `setupSheets` من القائمة المنسدلة
2. اضغط **Run** — سيتم إنشاء جميع الأوراق الـ16
3. (اختياري) شغّل `seedHadiths` لإضافة أحاديث تجريبية

> **تحديث قاعدة بيانات موجودة مسبقًا:** إذا كان لديك جدول بيانات تم إنشاؤه قبل إضافة تتبّع تشغيل
> الفيديو/الصوت/PDF، أضف يدويًا هذه الأعمدة إلى نهاية ورقة **الإنجاز**:
> `watched, videoPercent, videoPosition, audioPercent, audioPosition, pdfPercent, pdfLastPage, pdfTotalPages, startedAt, completedAt`
> (ورقة **الإعدادات** لا تحتاج تعديلًا — القيم الافتراضية 90% تُستخدم تلقائيًا حتى يغيّرها المدير من صفحة الإعدادات).

### ترقية قاعدة بيانات موجودة إلى «الكتب المتعددة»

> **لا تشغّل `setupSheets()`** على قاعدة بيانات قائمة — تعيد إنشاء حساب المدير الافتراضي.

1. استبدل محتوى ملفات `Code.gs` و`Config.gs` و`Hadiths.gs` و`Cycles.gs` و`Students.gs` و`Management.gs`
   وأضف الملف الجديد `Books.gs`.
2. شغّل الدالة **`setupBooks`** مرة واحدة من محرر Apps Script (آمنة عند إعادة تشغيلها). تقوم بـ:
   - إنشاء ورقتَي **الكتب** و**تعيين الكتب**،
   - إضافة عمود `bookId` إلى **الأحاديث** وعمودَي `bookId, bookTitle` إلى **الشهادات** (دون المساس بالبيانات الحالية)،
   - إنشاء الكتاب الأساسي «الأحاديث الأربعون» ونسب كل الأحاديث الحالية إليه،
   - تعيين الكتاب الأساسي لكل طالب معتمد حاليًا بتاريخ بداية الدورة النشطة (فلا يتغير مقرر أحد).
3. **Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy** — هكذا يبقى **نفس رابط `/exec`**.
   (اختيار «New deployment» ينشئ رابطًا جديدًا يجب تغييره في الويب والتطبيق.)
4. تحقّق: افتح `<رابط /exec>` بطلب POST بالجسم `{"action":"ping"}` — يجب أن يرجع `booksReady: true`.

**تحسين السرعة (2026-09-22):** أُضيفت ثلاثة إجراءات مُجمَّعة (`getStudentHome`,
`getIssueCertificateContext`, `getStudentProgressContext`) تجمع عدة عمليات قراءة في استجابة
واحدة بدل 3-6 طلبات منفصلة — كل طلب لـ Apps Script له كلفة زمنية شبه ثابتة بصرف النظر عن
حجم البيانات، فتقليل عدد الطلبات هو أهم عامل في سرعة التطبيق. لا تحتاج إعدادًا إضافيًا؛
تعمل تلقائيًا بعد رفع `Books.gs` و`Code.gs` المُحدَّثين. تطبيق أندرويد لم يُحدَّث بعد يستمر
بالعمل عبر الطلبات المنفصلة القديمة دون أي عطل.

**اعتماد الإنجاز والشهادة:** المشرف يعتمد إنجاز الطالب في كل كتاب ويكتب **تقدير الدرجة** (من «إنجاز الطلاب»)، والمدير وحده يصدر الشهادة بعد ذلك، وتحمل الشهادة نسبة الإنجاز والتقدير كما اعتمدهما المشرف. لا تصدر شهادة لكتاب لم يُعتمد إنجازه. ورقة اعتماد الإنجاز تُنشأ تلقائيًا عند تشغيل setupBooks() (أعد تشغيلها بعد رفع الملفات الجديدة؛ آمنة).

**كيف تعمل الكتب:** يحدد المدير لكل كتاب عدد الأيام وعناصر اليوم (من «إدارة الكتب»)، ويعيّن المشرف/المدير
كتبًا لطلاب محددين (من «متابعة الطلاب» أو من «إدارة الكتب ← الطلاب»). الطالب لا يرى إلا كتبه المعيَّنة،
وتبدأ أيام كل كتاب من تاريخ تعيينه للطالب. الشهادة تصدر لكل كتاب على حدة.

**حساب المدير الافتراضي:**
- البريد: `admin@zad.com`
- كلمة المرور: `admin123`
> غيّر كلمة المرور فور أول دخول من صفحة الملف الشخصي

## الخطوة 4: نشر Web App

1. في Apps Script: **Deploy → New deployment**
2. اختر النوع: **Web app**
3. الإعدادات:
   - **Description**: زاد الحلقات API
   - **Execute as**: Me
   - **Who has access**: Anyone
4. اضغط **Deploy**
5. انسخ رابط الـ Web App (ينتهي بـ `/exec`)

1. أنشئ ملف `.env` في جذر المشروع
2. أضف السطر التالي (مع استبدال الرابط برابطك):
```
VITE_APPS_SCRIPT_URL=https://script.google.com/macros/s/AKfycbyQCynYE0SRXjmnzRkhCxalaEqc2pcF3__uE_K4HEGO5c6O-pmmbyhdQ_RYPNSG9OrE/exec
```

## الخطوة 6: النشر على Vercel أو Netlify

### Vercel
1. ارفع المشروع إلى GitHub
2. في Vercel: **New Project** → اختر المستودع
3. في **Environment Variables**: أضف `VITE_APPS_SCRIPT_URL` برابطك
4. **Deploy**

### Netlify
1. ارفع المشروع إلى GitHub
2. في Netlify: **Add new site → Import an existing project**
3. في **Environment variables**: أضف `VITE_APPS_SCRIPT_URL`
4. **Deploy site**
